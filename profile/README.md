# tiny-playworks

Small games, playful tools, and interactive experiments.

## Projects

- **[Frontend Cultivation](https://frontend-cultivation.pages.dev)** — a xianxia-themed frontend clicker / management game.
- **[SpireWalker](https://spirewalker.miaoduidui.workers.dev)** — a card and strategy prototype.
- **SpireWalker UE** — an Unreal Engine prototype for the same small world.
- **mood_log** — a mobile mood diary and healing journal.
- **SpecFlow** — an experiment in structured interaction and flow.

## Direction

We build small playable worlds first: clear loops, lightweight systems, and tools that feel good to use.
